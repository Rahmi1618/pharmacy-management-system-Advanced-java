**Pharmacy Management System**
The Pharmacy Management System was developed as an Advanced Java course project to address these challenges by providing a **comprehensive, user-friendly desktop application** that automates pharmacy operations.
This project demonstrates the practical application of:
- Object-Oriented Programming (OOP) concepts
- GUI development with Java Swing
- Database integration using JDBC
- MVC (Model-View-Controller) architecture
- Team collaboration using Git/GitHub
